# 📊 HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **HR Analytics Dashboard** built using **Power BI** to analyze employee attrition, workforce demographics, and key HR metrics. The dashboard transforms raw HR data into meaningful business insights through data cleaning, Power Query transformations, DAX calculations, and interactive visualizations.



## 🎯 Project Objectives

- Analyze employee attrition across the organization.
- Monitor key HR KPIs.
- Analyze workforce distribution by department, salary, age group, and gender.
- Visualize employee job satisfaction.
- Support data-driven HR decision-making.



## 📂 Dataset

The dataset contains employee information including:

- Employee ID
- Department
- Gender
- Age
- Salary
- Job Role
- Education
- Job Satisfaction
- Attrition
- Total Experience



## 🧹 Data Preparation

Data preparation was performed using **Power Query** by:

- Importing the HR dataset
- Cleaning and transforming the data
- Correcting data types
- Preparing the dataset for reporting



## 🧮 DAX Measures

The following DAX measures were created:

- Attrition Count
- Attrition Rate (%)



## 📈 Dashboard Features

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Experience
- Department-wise Attrition
- Salary Slab Analysis
- Gender Analysis
- Age Group Distribution
- Job Satisfaction Matrix



## 💡 Key Insights

- Total Employees: **1,417**
- Active Employees: **1,186**
- Attrition Count: **231**
- Attrition Rate: **16.3%**
- The dashboard provides insights into employee demographics and attrition trends.
